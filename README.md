# مِـرْصَـاد — منظومة مراقبة تجمعات مياه الأمطار والسيول الذكية
### MIRSAD — Smart Urban Road Flood Monitoring & Alert System

لوحة تحكم تفاعلية ذكية متكاملة لإدارة ومراقبة الطرق والأنفاق أثناء مواسم الأمطار والسيول، مزودة بنظام ملاحة ذكي وتوجيه آلي للمسارات البديلة، وحساب دقيق لمصفوفة عبور المركبات.

---

## 🌟 المميزات الرئيسية (Key Features)

1. **واجهة مركز تحكم ذكية (Command Center UI)**:
   - تصميم داكن عالي التقنية بنمط Glassmorphism ومؤشرات حية للحساسات الميدانية.
   - دعم كامل للغة العربية واتجاه النص (RTL) مع خطوط عصرية.

2. **محاكاة تفاعلية لحساسات إنترنت الأشياء (IoT Sensors)**:
   - شريط تمرير تفاعلي لمحاكاة منسوب المياه من 0 إلى 50 سم.
   - سيناريوهات جاهزة للعرض التقديمي (أجواء مستقرة، هطول مفاجئ، سيول جارفة).
   - رصد حي لمعدل تدفق المياه، رادار الأمطار، والتحكم بمضخات الصرف ولوحات الطرق (VMS).

3. **خريطة جغرافية تفاعلية حية (Interactive Folium Map)**:
   - تلوين ديناميكي لمسار الطريق:
     - 🟢 **أخضر**: آمن (أقل من 12 سم).
     - 🟡 **برتقالي**: تحذير وحذر (12 - 24 سم).
     - 🔴 **أحمر**: خطر وإغلاق الطريق (25 سم فما فوق).
   - تفعيل مسار تحويلة ملاحية بديلة وآمنة (خط أزرق متقطع) تلقائياً عند غمر الطريق.

4. **مصفوفة أمان عبور المركبات (Vehicle Clearance Matrix)**:
   - 🚗 **سيارات السيدان والصغيرة**: حد الأمان حتى 12 سم، تحذير حتى 18 سم، وممنوع العبور بعد ذلك.
   - 🚙 **سيارات الدفع الرباعي (SUV & 4x4)**: حد الأمان حتى 25 سم، تحذير حتى 35 سم، وممنوع بعد ذلك.
   - 🚚 **الشاحنات وفرق الطوارئ والدفاع المدني**: ممر مسموح حتى 40 سم.

5. **سجل الأحداث وتنبيهات الأزمات المباشر (Incident & Event Log)**:
   - توثيق فوري لجميع القرارات وإجراءات الطوارئ الذكية بتوقيت دقيق.

---

## 🚀 طريقة التشغيل محلياً (Local Setup)

1. **تثبيت المتطلبات**:
```bash
pip install -r requirements.txt
```

2. **تشغيل التطبيق**:
```bash
python -m streamlit run app.py
```
